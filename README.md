# 吉田中小企業診断士事務所 公式ポートフォリオサイト

IT/DX支援、建築改修、スタートアップ育成を強みとする「実践型中小企業診断士」の公式ポートフォリオサイトです。
GitHub Pagesを活用し、自身の技術力（GAS, Gemini API, Web制作）を体現する形で構築されています。

## 公開URL
https://yoshidaagri.github.io/profile/

## 特徴
*   **技術主導型**: WordPress等のCMSを使用せず、HTML5/CSS3/JavaScriptで構築。
*   **Gemini AI活用**: Google Antigravity (Gemini Agent) との協働プロセスにより開発。
*   **レスポンシブデザイン**: モバイルからデスクトップまで最適化された表示。

## ディレクトリ構成
```
/
├── index.html          # トップページ
├── subsidy.html        # 補助金支援詳細ページ
├── .nojekyll           # GitHub Pages Jekyll処理無効化設定
├── README.md           # 本ファイル
└── assets/
    ├── css/            # スタイルシート (style.css)
    ├── js/             # スクリプト (main.js)
    └── images/         # 画像リソース (logo.png)
```

## 技術スタック
*   HTML5
*   CSS3 (Variables, Grid, Flexbox)
*   JavaScript (Canvas API, DOM Manipulation)
*   Font: Noto Sans JP, Fira Code

## 開発・更新フロー
本サイトはローカル環境で開発し、GitHubへプッシュすることで自動的に公開（デプロイ）されます。
